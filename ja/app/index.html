接続の予算を計算する

バックエンド接続 = 直接つなぐ数 + (ロール数 x モード数 x プールサイズ) + Data APIのプール + ほかのサービス。max_connections と、プーラーのクライアント上限に収まるか？

-アプリが開くクライアント接続
-Postgresへのバックエンド接続
-合計: バックエンド + Data API + ほかのサービス
-max_connections から予約分を引いた数

これは計算のモデルで、あなたのプロジェクトの実測ではありません。サイズごとの上限はSupabaseのドキュメント（2026-11-03確認）によります。上限でのエラー、60秒の待ち時間、プールの掛け算、Data APIのプールは、ホスト版ではなく、私のローカルのラボ（Nano並みの上限にしたSupabase CLI）で見たことです。このページはサーバーを呼びません。
